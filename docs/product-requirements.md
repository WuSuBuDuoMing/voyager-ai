## 1. 产品概述

### 1.1 产品定位

AI 旅行计划助手是一款基于微信小程序的智能旅行规划工具，致力于帮助用户从零开始构建完美旅行。通过 AI 智能推荐、可视化预算管理、实用行李清单等功能，让旅行规划变得简单、高效、有趣。

### 1.2 目标用户

| 用户群体 | 画像描述 | 核心需求 |
|----------|---------|---------|
| **自由行旅客** | 20-35 岁，喜欢自主规划行程的年轻用户 | 快速生成行程、管理预算、整理行李 |
| **情侣/蜜月旅行者** | 计划浪漫旅程的情侣或新婚夫妇 | 精细化行程安排、美食探索 |
| **家庭出游者** | 带孩子或老人出行的家庭 | 行李清单管理、费用控制 |
| **背包客** | 独自旅行、预算敏感的旅行者 | 预算管理、行程灵活调整 |
| **商务出行者** | 出差兼顾旅游的上班族 | 高效规划、时间管理 |

### 1.3 使用场景

1. **行前规划**：决定旅行目的地后，快速创建旅行计划，设置日期、预算，使用 AI 生成行程。
2. **行中管理**：旅行过程中查看每日行程、记录消费、打卡景点、品尝美食。
3. **行后记录**：旅行结束后撰写日记、标记已去景点、整理预算数据。
4. **碎片时间**：在通勤或休息时浏览旅行列表、查看倒计时、浏览美食攻略。

### 1.4 产品愿景

> 让每一次旅行都井然有序，让每一笔花费都清清楚楚，让每一段回忆都值得珍藏。

| 子功能 | 描述 | 优先级 |
|--------|------|--------|

| 目的地 | 文本输入 | 是 | 1-20 个字符 |

| 返回日期 | 日期选择器 | 是 | 不得早于出发日期 |
| 出行人数 | 数字输入 | 是 | 1-20 人 |

| 行程节奏 | 选择器 | 否 | 4 种节奏可选 |
| 总预算 | 数字输入 | 否 | >= 0 |
| 住宿信息 | 文本输入 | 否 | 最多 50 字 |

## 6. 数据模型

### 6.1 Trip（旅行计划）

```javascript
{
  id: string,               // 唯一标识，格式：trip_timestamp_random
  destination: string,      // 目的地名称
  coverImage: string,       // 封面图 URL
  startDate: string,        // 出发日期，格式：YYYY-MM-DD
  endDate: string,          // 返回日期，格式：YYYY-MM-DD
  peopleCount: number,      // 出行人数
  totalBudget: number,      // 总预算（元）
  spentBudget: number,      // 已花费金额（元）
  style: string,            // 旅行风格（relaxation/adventure/culture/food/...）
  pace: string,             // 行程节奏（relaxed/moderate/tight/...）
  status: string,           // 状态（planning/upcoming/ongoing/ended）
```
